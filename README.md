# 🎓 Engenharia de Nuvem & Arquitetura AWS

Repositório oficial de estudos práticos, laboratórios de infraestrutura e arquiteturas desenvolvidas com **Python (FastAPI)** e **React**. 

Este repositório funciona como um caderno de laboratório de uma formação acadêmica focada em transformar conceitos teóricos de nuvem em sistemas reais, escaláveis e resilientes.

---

## 📚 Progresso da Formação

- [ ] **Semestre 1 (Júnior):** Fundamentos AWS, IAM, VPC, S3, RDS e Boto3
- [ ] **Semestre 2 (Pleno):** Terraform, SQS, SNS, EventBridge, Lambda e DynamoDB
- [ ] **Semestre 3 (Sênior):** ECS/Fargate, API Gateway, Secrets Manager e OpenTelemetry
- [ ] **Semestre 4 (Especialista):** Kubernetes (EKS), Helm, ArgoCD, CI/CD e DevSecOps
- [ ] **Semestre 5 (Arquiteto):** Sistemas Distribuídos, Step Functions, Chaos Engineering e FinOps

---

## 🛠️ Stack Tecnológica

* **Backend:** Python, FastAPI, Boto3, Pytest
* **Frontend:** React, TypeScript / JavaScript
* **Infraestrutura & DevOps:** Docker, Docker Compose, Terraform, Kubernetes, MiniStack (Ambiente AWS local)
* **Observabilidade:** Prometheus, Grafana
